## Panorama versions

Repo keeps versioned sources `tracker_vN.xml`, `menu_vN.xml`, `hud_vN.vcss`. `PanoramaVersion` in [`Version.cs`](../src/Challenges/Version.cs) selects those at runtime. Bump only when panel ids / dialog vars / classes / structure would break old DLLs; keep older generations in the published addon.

## Theme / type / bars

Chrome: dark gradient `#12171e`→`#0b0f14`, borders `#ffffff14`, gold `#f0a531` (`gui.theme` = `gold`; `theme-*` via `HudTheme.Apply`). Themes from [`tools/hud_themes.py`](../tools/hud_themes.py). CT/T: `#96c8fa` / `#eabe54`. Text tokens: ink `#f5f7fa`, ink-soft `#e8eef4`, muted `#a3acb6` (header of `hud_v4.vcss`). Type scale **14 / 16 / 18** (floor 14; card titles 16). **Accent only** for active state, bars, accent bar, sorted column and own entries (`is-you`, `is-self`); section labels are muted. Semantic colours never follow the theme: done = success check, broken = danger dash, open = accent bar (state by shape, not colour alone). One container level per card (no box per task line). Spacing on a 4px grid. Menu fades 0.25s in / 0.18s out; tracker keeps 1.0s. Bars: `p0`…`p100` (`SetStepPercent` 10% challenge fills; `SetPercent` 1% = timer start position; `p0` = 0%). Tracker timer is drained by the client: start p-class, next tick `span-N` + `is-running` (`Tracker.StartTimer`), no writes while it runs.

## Text

Labels use `text="{s:…}"` except literal `Label.MenuCredit`. Server fills from `lang/en.json` / `lang/de.json` via `Context.Text`. Blueprint titles: `Titles.For` (culture → two-letter → first). Formats: `hud.format.page|percent|count|rank`, `hud.menu.when.*`. Completer self-slot: `hud.menu.you` + `is-you`.

## Terms

**Blueprint** = YAML definition. **Challenge** = winnable instance (all visible tasks done). **Task** = step; `visible: false` stays off both HUDs. Modules inherit `Module`.

## Server can only

1. Dialog var on the layout root card → Label text (never path/colour).
2. `SetHasClass` on a panel **id**.

No panel create / width / colour / image from C#. Layout edits need VPK republish.

**Authored state:** [`HudAuthored.g.cs`](../src/Challenges/Hud/HudAuthored.g.cs) (generated by `make panorama` from the current layouts) lists the classes of every id'd panel. On a slot that was never written since our entity spawned (`_pristine`), a class cache miss falls back to it, so the first paint sends only deviations from the XML. Never edit the `.g.cs`; change the XML and rerun `make panorama`.

**Open:** chat command → `HudMenu.RequestOpen` (0.2s timer, token-cancelled by a second command, close or release) → `Menu.Open`. Layouts are spawned by `CustomHud.WarmUp` 1s after map start. Timers are cancelled by token, never `Kill()`ed.

**Round restart:** layouts survive rounds; client resets XML defaults while server keeps last classes/vars. `HudDriver.EventRoundStart` → `CustomHud.ResetRound()` → `Tracker`/`Menu`.`WriteDefaults` + drop ledger. **XML defaults must match `WriteDefaults`.** Never Kill/respawn live layouts; `Shutdown` only on map end/unload.

**Fade:** show = `ph-fading` then clear next frame; hide = `ph-fading` 1s then `ph-off` (not in the same write). **Tick:** 2 slots/tick; `Tracker.Refresh` paints only in freeze or progress hold.

`make panorama` validates ids/`{s:…}` against C# and the 1244 dialog-var cap.

### Tracker ([`Tracker.cs`](../src/Challenges/Hud/Tracker.cs))

Top-right 420px, never clickable. Title/count/hint (`!c`); up to 5 rows (`gui.tracker_rows` default 3). **Freeze** (`mp_freezetime > 0`): unsolved, % desc, unsolved tasks only, drain = freezetime. **Progress:** `ShowProgress` kinds Progress/TaskSolved/ChallengeSolved; challenge solved → up-next after `gui.progress_duration`. **Rule broken:** queue via `ShowRuleBroken`; freeze clears queue; after freeze, remaining breaks play. **Intermission:** `cs_intermission` → `Tracker.Hide` (map vote).

### Menu ([`Menu.cs`](../src/Challenges/Hud/Menu.cs))

`!c` → mouse capture. Filters all/solved/progress/ending/starting with counts; paginated list (4 cards/page, equal height, no scroll); cards `ch-mrow-0…3` are non-clickable; scoreboard inspect sets `MenuSubjectSteamId` (list shows that player’s progress); ending/starting windows 7d. Tracker `z-index` 99998 under open menu.
