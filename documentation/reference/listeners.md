# Listeners

Use a **task type** as the task `type:` in your challenge file. Listeners are CounterStrikeSharp hooks (not game events). Open a listener page for the attributes (rule keys) you can check. For game events, see [Events](events.md).

Source: CounterStrikeSharp `main` (synced tip `653d651f1ac0`).

## Common types

| Task type | Typical use |
|-----------|-------------|
| `on_player_chat` | Player sent a chat message (listener) |
| `player_chat` | Player sent a chat message |
