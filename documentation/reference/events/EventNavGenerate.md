# EventNavGenerate (nav_generate)

CSS game event `nav_generate` (`EventNavGenerate`).

Who gets credit: **all connected players**.

## Task types

Put one of these in your task `type:` field:

- `nav_generate`

## Minimal YAML

Save under `blueprints/`. Add rules from the table below — see [Rules](../rules.md).

```yaml
tasks:
  - id: example
    type: nav_generate
    amount: 1
    rules: []
```
