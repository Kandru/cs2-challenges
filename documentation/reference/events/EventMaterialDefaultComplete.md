# EventMaterialDefaultComplete (material_default_complete)

CSS game event `material_default_complete` (`EventMaterialDefaultComplete`).

Who gets credit: **all connected players**.

## Task types

Put one of these in your task `type:` field:

- `material_default_complete`

## Minimal YAML

Save under `blueprints/`. Add rules from the table below — see [Rules](../rules.md).

```yaml
tasks:
  - id: example
    type: material_default_complete
    amount: 1
    rules: []
```
