# EventBulletImpact (bullet_impact)

CSS game event `bullet_impact` (`EventBulletImpact`).

Who gets credit: the **event player(s)** listed under challenge types.

## Challenge types

Put one of these in your task `type:` field:

- `bullet_impact`
