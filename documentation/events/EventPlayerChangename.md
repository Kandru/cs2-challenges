# EventPlayerChangename (player_changed_name)

CSS game event `player_changename` (`EventPlayerChangename`).

Who gets credit: the **event player(s)** listed under challenge types.

## Challenge types

Put one of these in your task `type:` field:

- `player_changed_name`
